# Skill: Narrative & Story Design

## When to use this skill
- User asks to create a story, characters, or dialogue for a game
- User needs a quest/mission narrative structure
- User wants world-building or lore documentation

## Decision Tree

| Request | Action |
|---|---|
| "Write a game story" | Apply 3-Act structure → define protagonist arc → create story bible |
| "Design characters" | Create character sheet with motivation/conflict/arc |
| "Design dialogue system" | Define branching vs linear → write dialogue trees |
| "Build the game world" | Create lore bible → define factions/history/rules |

## Step-by-Step Execution

### Step 1 — Story Structure (3-Act for Mobile)
Mobile games need condensed, impactful narratives:

| Act | Purpose | Mobile Adaptation |
|---|---|---|
| **Act 1: Hook** | Introduce world + conflict | First 5 minutes — skip lengthy cutscenes |
| **Act 2: Journey** | Escalate challenge + develop character | Told through gameplay progression |
| **Act 3: Climax** | Resolve conflict + reward player | Boss fight + emotional payoff |

### Step 2 — Character Design Sheet

```
CHARACTER: [Name]
ROLE: [Protagonist / Antagonist / Mentor / Companion / NPC]
VISUAL ARCHETYPE: [Warrior / Mage / Rogue / etc.]
MOTIVATION: [What do they want?]
FLAW: [What holds them back?]
ARC: [How do they change through the story?]
GAMEPLAY FUNCTION: [What does the player DO with this character?]
SIGNATURE LINE: [One memorable quote]
DESIGN NOTES FOR ARTIST: [Visual description, mood, color associations]
```

### Step 3 — Dialogue System Type

| Type | Best For | Complexity |
|---|---|---|
| **Linear** | Mobile casual, story-driven levels | Low |
| **Branching (2–3 choices)** | RPG-lite, visual novel elements | Medium |
| **Hub-and-Spoke** | NPC conversations with topics | Medium |
| **Full Tree** | Deep RPG, consequence-driven narrative | High |

### Step 4 — Quest/Mission Template

```
QUEST: [Name]
TYPE: [Main / Side / Daily / Event]
GIVER: [Who assigns this?]
OBJECTIVE: [Clear, measurable goal]
NARRATIVE CONTEXT: [Why does this matter to the story?]
REWARD: [What the player receives]
UNLOCK CONDITION: [What must happen before this quest appears?]
ESTIMATED DURATION: [How long to complete?]
```

## Best Practices
- Mobile players skip cutscenes — deliver story THROUGH gameplay, not before it
- Every character must serve a gameplay purpose (not just narrative decoration)
- If the story can be removed and the game still works, the story is not integrated enough
- Use environmental storytelling: visual cues, item descriptions, background details
