# Rule GD-04: Monetization Principles (IAP + Ads Hybrid)

## Overview
Mobile F2P monetization must balance revenue with player satisfaction. Aggressive monetization destroys retention. The golden rule: **Players should WANT to pay, never NEED to pay.**

## 1. Core Monetization Ethics

### Anti-Pay-to-Win
- Paying players may progress **faster**, but never gain **exclusive** mechanical advantages unavailable to free players
- Competitive modes (PvP, Leaderboards) must have skill-based outcomes, not wallet-based
- Cosmetic monetization is always preferred over power monetization

### Respect the Player's Time
- A free player should be able to experience 100% of content — just slower
- Energy systems must allow a minimum meaningful session (≥ 3 minutes) before gating
- Never gate tutorial or onboarding behind monetization walls

### Transparency
- Always show odds for random rewards (gacha, lootbox) — many jurisdictions require this legally
- Show the "value" comparison for IAP packages clearly

## 2. Ads Strategy

### Rewarded Video Ads (Primary)
- Player-initiated ONLY — never force an ad without consent
- Clear value proposition: "Watch 30s → Get 2x rewards"
- Limit: 5–8 rewarded ads per day (diminishing returns on engagement)
- Strategic placement: after level completion, in shop, for extra life/continue

### Interstitial Ads
- NEVER after a player death or failure (causes rage-quit)
- Acceptable after: level completion, returning to menu, natural break points
- Frequency cap: max 1 per 3 minutes of gameplay
- Always provide a "Remove Ads" IAP option

### Banner Ads
- Lowest priority — minimal revenue, high annoyance
- If used: bottom of screen only, never overlapping gameplay
- Consider removing entirely for better retention metrics

## 3. IAP Package Design Principles

### Starter Pack (One-time)
- Best value in the entire game — hook the first purchase
- Price: $0.99 – $2.99
- Must feel like "stealing" — 5x–10x normal value

### Battle Pass / Season Pass
- Free tier + Premium tier structure
- Free tier must feel rewarding (not empty filler)
- Premium tier: cosmetics + acceleration, never exclusive power

### Currency Packages
- Always offer 3–5 tiers (anchoring effect)
- Best value at highest tier (whale targeting)
- Always show "BEST VALUE" / "MOST POPULAR" tags

### Subscription Model
- Only if the game has daily engagement hooks
- Provide daily drip rewards (login to claim)

## 4. Conversion Funnel Metrics
When designing monetization, always define target KPIs:

| Metric | Casual Target | Midcore Target |
|---|---|---|
| Day 1 Retention | ≥ 40% | ≥ 35% |
| Day 7 Retention | ≥ 15% | ≥ 12% |
| Day 30 Retention | ≥ 5% | ≥ 4% |
| Ad ARPDAU | $0.03 – $0.08 | $0.05 – $0.15 |
| IAP Conversion Rate | 2% – 5% | 3% – 8% |
| ARPPU (monthly) | $5 – $15 | $10 – $50 |
